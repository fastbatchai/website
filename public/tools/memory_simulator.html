Where the vectors come fromA real model computes k, v and q with learned weights. Here each word gets a fixed random unit key (the same word always gets the same key), a random value that differs per position, and q = k. Words are lowercased, so "The" and "the" share a key.
The gate αShown under each word. Only the SSM and Gated DeltaNet rules use it: the old state is multiplied by α before the new token is written. Here α is a fixed random number per word, standing in for a learned gate.
